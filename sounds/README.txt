Optional: put real sound files in this folder so they load on every device.

1. Copy your audio files here, e.g. 07_hurricane.mp3
2. List them in manifest.json by cue number:
   { "07": "07_hurricane.mp3", "33b": "all_star_intro.mp3" }
3. Re-upload the folder.

Files you drag onto a tile in the browser are saved only on that device,
and they take priority over files listed here.
